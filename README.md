# Essência do Olhar

Site premium para design de sobrancelhas, desenvolvido com React e Vite.

## Desenvolvimento

- `npm install`
- `npm run dev`

## Deploy

Importe este repositório na Vercel. O framework será detectado como Vite.

## Observação

O formulário de agendamento abre uma conversa no WhatsApp. Configure o número real em `src/main.jsx` antes de publicar. A integração com a API oficial do WhatsApp pode ser conectada posteriormente por um backend seguro.
